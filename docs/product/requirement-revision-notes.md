# 修改意见

### 用户角色定义修改意见

根据目前登录注册方式，需去除访客角色定义。统一注册后登陆，未注册\登录用户能停留登录\注册界面无法浏览已审核+活跃物品列表；使用智能匹配；访问数据看板,已禁用用户无法登陆系统，由管理员操作封禁。

更新个人资料，注销账号等个人中心的功能，UI设计不符合网站设计逻辑，仿照权威网站的个人中心UI模块样式，结合目前项目网站设计风格，重新设计出好用美观符合网站逻辑的个人中心界面并且砍掉头像上传与更新的功能。

### 管理员审核模块新增需求

增加审核列表批量审核功能，一键批量审核通过，驳回功能不支持（需要发送站内通知）；用户管理功能，支持用户信息删除，删除后用户信息逻辑删除；用户角色变更功能，管理员禁用的用户拉入黑名单，无法登录。

### 物品认领/归还模块修改意见

申请认领/归还功能：发送站内通知+邮件给发布者，信息内要求包含申请人的联系方式，可从用户账户获取电话号码编入站内信和邮件。

防重复申请功能：同物品+同用户未读通知存在时拒绝，返回异常信息：重复提交

确认/拒绝功能：取消确认/拒绝功能，改为发布者对自己的物品点击已归还或者已认领按钮，改变物品状态，改变状态的物品不再展示在物品列表，转为个人信息中心的历史记录模块里保留记录。

### 数据统计模块 修改意见

首页看板，显示统计当日物品总数/失物/拾物/总计找回数量，保留当前卡片模版，把今日找回修改为总计找回；每次用户对已发布物品更改状态为已归还和已认领时数值自动触发数值+1.砍掉分类占比，累计活跃功能

### 认领/归还语义规则修改

删去发布者确认→物品状态 claimed；拒绝→不变。双向通知+邮件按钮的功能，改为

在自己发布的失物下点击已找回按钮→物品状态 claimed；已认领按钮→物品状态 claimed；
