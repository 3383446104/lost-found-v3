> 方法：全部变体在 `CROSS_PENALTY_ENABLED=False` 下对比（惩罚是通道无关后处理，不掺入消融归因）；`fused_online` 为线上口径参照。

> 口径：P@R≥0.9 = 手动阈值（Recall ≥ 0.90 最高分位）处的 Precision；R@P≥0.9 = 自动阈值（Precision ≥ 0.90 最低分位）处的 Recall。


## 2. 结论

- **融合 vs 单通道（排序口径）**：融合 Recall@3 = 1.0，最优单通道为「仅跨模态（映射后）」（1.0）→ 融合≥最优单通道（差 +0.0000）；Recall@1 融合 0.7778 vs 单通道最优 0.75。
- **融合 vs 单通道（自动口径，P≥0.9）**：单通道 R@P≥0.9 分别为 `text_only`=0.1111、`img_only`=—、`cross_only`=—；融合为 0.5556。**任何单通道都无法在 P≥0.9 下保持召回（或直接无解），只有加权融合**能同时满足高精度与召回——这就是「加权融合」的实证价值。
- **主辅加权 vs 等权**：Recall@3 为 1.0 vs 1.0（差 +0.0000）；手动阈值 P 为 0.8049 vs 0.8250——样本量下两者相当，0.75/0.25 的语义（主辅证据）优先于在该集上追平权。
- **阶段5 惩罚**（线上口径 vs 无惩罚）：Recall@3 为 1.0 vs 1.0；手动阈值 P 为 0.7500 vs 0.8049，自动阈值 R 为 0.6111 vs 0.5556（惩罚换自动推送召回，换手动口径精度）。
