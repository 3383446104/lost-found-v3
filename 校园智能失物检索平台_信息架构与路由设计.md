## 2. 路由设计

### 2.1 完整路由表

| 路由 | 组件 | 布局 | 权限 | meta | 说明 |
|------|------|:----:|------|------|------|
| `/login` | LoginView | 独立 | 未登录 | `{ requiresGuest: true }` | 校园航拍背景 + 毛玻璃卡片 |
| `/register` | RegisterView | 独立 | 未登录 | `{ requiresGuest: true }` | 同上风格 |
| `/` | — | — | — | `redirect: '/items'` | 根路径重定向 |
| `/items` | HomeView | Default | 已登录 | `{ requiresAuth: true }` | 首页：统计卡片 + 公告栏 + 物品列表 |
| `/items/:id` | ItemDetailView | Default | 已登录 | `{ requiresAuth: true }` | 物品详情 + 操作区 |
| `/publish` | PublishView | Default | 已登录 | `{ requiresAuth: true }` | 发布物品（支持 ?edit=id 编辑模式） |
| `/match` | MatchView | Default | 已登录 | `{ requiresAuth: true }` | 智能匹配面板 |
| `/admin` | AdminView | Default | 管理员 | `{ requiresAuth: true, requiresAdmin: true }` | 物品审核 + 用户管理 + 公告管理 |
| `/notifications` | NotificationsView | Default | 已登录 | `{ requiresAuth: true }` | 通知列表 |
| `/profile` | ProfileView | Default | 已登录 | `{ requiresAuth: true }` | 个人中心（重设计） |

### 2.2 路由守卫逻辑

```javascript
// v3.3 路由守卫
router.beforeEach((to, from, next) => {
  const authStore = useAuthStore()

  // 恢复持久化登录态
  if (!authStore.token) {
    authStore.restore()
  }

  const isLoggedIn = !!authStore.token
  const isDisabled = authStore.user?.role === 'disabled'

  // 1. 已禁用用户 → 清除登录态 → 跳转登录页
  if (isLoggedIn && isDisabled) {
    authStore.logout()
    next('/login')
    return
  }

  // 2. 需登录但未登录 → /login
  if (to.meta.requiresAuth && !isLoggedIn) {
    next('/login')
    return
  }

  // 3. 仅未登录页面但已登录 → 按角色跳转
  if (to.meta.requiresGuest && isLoggedIn) {
    next(authStore.isAdmin ? '/admin' : '/items')
    return
  }

  // 4. 需管理员但非管理员 → 首页
  if (to.meta.requiresAdmin && !authStore.isAdmin) {
    next('/items')
    return
  }

  next()
})

// 全局后置守卫：刷新未读消息（仅已登录时）
router.afterEach((to, from) => {
  const authStore = useAuthStore()
  if (authStore.token && authStore.user?.role !== 'disabled') {
    const notifStore = useNotificationStore()
    notifStore.fetchUnreadCount()
  }
})
```

### 2.3 路由参数

| 路由 | 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|:----:|------|
| `/items/:id` | `id` | number | ✅ | 物品 ID |
| `/publish` | `edit` | number | ❌ | 编辑模式下的物品 ID |
| `/items` | `type` | string | ❌ | 筛选类型：lost / found |
| `/items` | `category` | string | ❌ | 筛选分类 |
| `/items` | `keyword` | string | ❌ | 搜索关键词 |
| `/items` | `page` | number | ❌ | 页码 |

### 2.4 v3.2 → v3.3 路由变更对照

```diff
  /login           meta: { requiresGuest: true }     ← 不变
  /register        meta: { requiresGuest: true }     ← 不变
- /items           meta: { }                          ← v3.2 公开
+ /items           meta: { requiresAuth: true }       ← v3.3 需登录
- /items/:id       meta: { }                          ← v3.2 公开
+ /items/:id       meta: { requiresAuth: true }       ← v3.3 需登录
  /publish         meta: { requiresAuth: true }       ← 不变
- /match           meta: { requiresAuth: true }       ← v3.2 需登录
+ /match           meta: { requiresAuth: true }       ← 不变
  /admin           meta: { requiresAuth: true, requiresAdmin: true } ← 不变
  /notifications   meta: { requiresAuth: true }       ← 不变
```
