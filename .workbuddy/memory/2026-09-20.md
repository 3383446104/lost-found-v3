### 关键方法（可复用：图库素材获取链路）
1. **本机网络**：直连 Pexels/Unsplash 网页 403（WAF 拦非浏览器请求），但 **图片 CDN 可达**：
   - ✅ `images.pexels.com`、`images.unsplash.com`（加 UA 头即可下真实 JPEG）
   - ❌ `cdn.pixabay.com` 403、`api.openverse.org` 超时
2. **获取直链靠工具侧网络**：`WebFetch` 抓 `https://www.pexels.com/search/<英文关键词>/` 页面，
   提示词要求「列出所有含 images.pexels.com/photos/ 的 URL」→ 一次能拿到 20+ 条真实直链
   （含 photo id 与 slug，可拼出文件名与来源页 URL）。
3. **下载**：`urllib` + 直连 ProxyHandler + 浏览器 UA，URL 追加 `&auto=compress&cs=tinysrgb&w=1200`
   控制尺寸；magic bytes 校验（JPEG/PNG）+ 大小校验 + 3 次重试。
4. **筛选原则**：只取「纯物品、不含人物」的照片——Pexels 的关键词结果常混入人像
   （如 `backpack` 多为背包客、`umbrella` 多为雨中街景），需在提示词里明确排除。
