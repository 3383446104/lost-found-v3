## 时间衰减失效修复 + 参数调温和（用户说"要放入新日期物品测试"→ 先修前提）

用户准备发布**新日期物品**做测试 → 我指出关键前提：**当前时间衰减失效**（days_old 恒 0），
不修的话新老物品分数不会有差异，**测不出东西**。遂按上一轮推荐的温和方案修复。

### 根因（「静默失败」家族又一例）
- `api/items.py` / `services/match_service.py` 各自 `try/except` 解析 `created_at`：
  `datetime.fromisoformat("2026-07-02 01:06:44")` **解析成功但返回 naive** →
  与 aware 的 `datetime.now(timezone.utc)` 相减抛 **TypeError** → 被 `except Exception` 吞成
  `days_old = 0` → **衰减恒 ×1.0**，且**无任何日志**，外部完全无法察觉。
- SQLite `CURRENT_TIMESTAMP` 存 UTC 但不带时区标记 —— 这是触发条件。

### 修法（一处修好、两处受益、可测）
- 新增公共函数 **`app/utils/time_utils.days_since_utc(time_value, *, now=None)`**：
  统一处理 ISO（含 Z/偏移）、SQLite 空格格式（含微秒）、naive→补 UTC；解析失败返回 0 **并记 warning**。
- 两个调用点改用它，删除各自的 try/except 兜底。
- 新增 **`tests/test_time_decay.py`（5 例）**：核心守卫「SQLite 无时区格式必须算出真实天数（而非 0）」
  + ISO 三形态/微秒/未来/非法 + 乘数符合配置 + **集成断言「days_old 增大 → 分数必须下降」**。
- 参数调温和（用户确认）：`MATCH_DECAY_DAYS` 90→**240**、`MATCH_DECAY_FLOOR` 0.2→**0.6**。
  原因：原 90/0.2 过激，76 天物品被打到 12%，配合 0.35 阈值会让**结果集体消失**；
  温和档下老物品 38% **仍可见 → 无需改动阈值体系**（这是选温和档的关键理由）。

### 实测（真实模型 + 真实库，端到端）

- 解析层：库中 6 件物品正确算出 80~81 天（旧实现恒 0）。
- 端到端：`POST /api/items/match` → item64 = 0.3849（38%）。
- 测试：213 → **218 用例 / 216 passed / 2 门控 skip / 0 failed**。
- 提交 `ca67693`；服务已重启加载新代码（后端 8000 运行中）。

## 首页「智能查找」栏外观修复（用户截图反馈）

用户发截图要求分析外观问题 → 定位后用户说"直接改"，已修（提交 `d7099b0`）。

### 根因（Element Plus 用法陷阱）
`el-input` 的 **`#append` 插槽自带浅灰背景**（`.el-input-group__append`），把
`type="primary"` 的按钮塞进去后**主色被灰底覆盖** → 全页最重要的操作看起来像
浅灰禁用态；且 append 的直角边框会抹平输入框右侧圆角 → 交界处视觉断层。
（`HomeView.vue` 的智能查找入口即此写法。）

### 修法（分离布局）
- 移除 `#append`，按钮提升为同级元素，包进 `.smart-bar`（flex + gap 12px）；
- `.smart-btn { flex-shrink: 0; font-weight: 600 }`；窄屏媒体查询下按钮占满整行；
- 文案精简：placeholder 由 41 字缩到「描述一下物品，例如：…」；hint 去掉与
  placeholder 重复的「用自然语言描述即可，无需纠结关键词」。

### 验证与教训
- 转译产物核对（smart-bar/smart-btn 生效、append 痕迹 0）+ 构建 ✓ 2.38s + SFC 检查 0 问题。
- ★ **可复用经验**：Element Plus 里 `#append`/`#prepend` **不是**放主按钮的地方
  （它们是有背景的附加块）。主操作应作为同级元素独立布局；只有「单位/后缀文本」
  这类无强调需求的内容才适合 append。
- ★ 环境坑：Bash 工具传含嵌套引号的 `python -c` 会被 shim 解析失败
  （`syntax error near unexpected token '('`）→ **一律写成临时 .py 文件再跑**。
